# POS Minimarket

Sistema de punto de venta (POS) e inventario para minimarkets y almacenes de barrio,
configurable para uno o varios locales.

> **Estado:** Fase 0 (cimientos) en construcción.

- **Stack:** Java 21 + Spring Boot · Angular · PostgreSQL 17 · Docker Compose.
- **Diseño:** ver [`docs/PLAN.md`](docs/PLAN.md), [`docs/MODELO_DATOS.md`](docs/MODELO_DATOS.md),
  [`docs/API.md`](docs/API.md), [`docs/ROLES_PERMISOS.md`](docs/ROLES_PERMISOS.md) e
  [`docs/HISTORIAS_USUARIO.md`](docs/HISTORIAS_USUARIO.md).

Las instrucciones para levantar el entorno se agregarán al terminar la Fase 0.
