# T73 — Regenerar contrato (7)

> Archivo generado desde la fila T73 de `docs/PLAN.md` H.3 (Fase 5 — ventas avanzadas). Ante cualquier duda, manda el diseño de `docs/`.

## Objetivo
Regenerar contrato (7)

## Archivos permitidos
`frontend/openapi/**`, `frontend/src/app/api/**`

Las rutas abreviadas de la tabla del plan se leen así:
- `backend/.../<modulo>/**` y `<modulo>/...` (p. ej. `security/auth/refresh/**`, `sales/application/sale/**`) → `backend/src/main/java/cl/minimarket/pos/<modulo>/...`
- `features/...` → `frontend/src/app/features/...`
- `templates/pdf/...` → `backend/src/main/resources/templates/pdf/...`
- `db/demo/...` y `V2026...sql` → `backend/src/main/resources/db/demo/...` y `backend/src/main/resources/db/migration/...`
- Para cada carpeta de código de backend permitida, también puedes crear sus pruebas en la ruta equivalente bajo `backend/src/test/java/cl/minimarket/pos/...`. En frontend, los `*.spec.ts` van junto al código.

No toques nada más (ver `AGENTS.md` §2 y, si trabajas sin orquestador, §6).

## Dependencias
T70, T72. No empieces hasta que todas estén `entregada` o `aprobada`.

## Contexto que debes leer
- `docs/PLAN.md`: A.4 (módulos, APIs públicas y dependencias permitidas), A.5 (convenciones), sección L (notas obligatorias) y la fila T73 de H.3.
- `docs/API.md` F.2/F.3 de los endpoints que consume la pantalla; `docs/HISTORIAS_USUARIO.md`; `docs/PLAN.md` ADR-24 a ADR-29

## Qué hacer
1. Confirma que las tareas de las que dependes (T70, T72) estén `entregada` o `aprobada`.
2. Ejecuta el `verify` del backend (`AGENTS.md` §4): `OpenApiExportIT` regenera `frontend/openapi/openapi.json` con todos los endpoints actuales.
3. En `frontend/`: `npm run api:gen` y luego `npm run format:check && npm run lint && npm test -- --watch=false && npm run build`.
4. Comprueba que `openapi.json` contiene lo que exige el criterio de terminado. Si falta un grupo de endpoints, no lo inventes: repórtalo en la Entrega (significa que una tarea anterior no expuso su endpoint o no tiene las anotaciones de springdoc).

## Criterio de terminado
- `npm run api:gen && npm run build` en verde y `openapi.json` contiene promotions, customers, tax-documents y sale-returns
- Verificación de `AGENTS.md` §4 en verde.

## Notas del orquestador
- No edites a mano `openapi.json` ni `src/app/api/**`: solo se regeneran.
- Si `npm run build` falla porque una pantalla existente usa un tipo que cambió, corrige ese uso solo si es trivial y anótalo; si no, repórtalo.
